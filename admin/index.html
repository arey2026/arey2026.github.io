Configura la base de datos

El panel necesita una base de datos en la nube (Supabase) para guardar el inventario de forma segura y compartirlo entre dispositivos. Mientras tanto, la tienda muestra el catálogo de respaldo en modo de solo lectura.

  1. Crea un proyecto gratuito en supabase.com.
  2. En SQL Editor, ejecuta el archivo supabase/schema.sql.
  3. En Authentication → Users, crea tu usuario administrador y registra su ID en la tabla admins.
  4. Copia la URL del proyecto y la clave anon public en js/config.js.

Las instrucciones detalladas están en docs/INFORME.md, sección F.
