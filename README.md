# AJRO HOUSE · Tienda de perfumes

Sitio estático (GitHub Pages) con base de datos Supabase para inventario, pedidos y panel administrativo.

- Tienda: `index.html`
- Panel administrativo: `admin/`
- Esquema de base de datos: `supabase/schema.sql`
- Plantillas de Excel: `plantilla/`
- **Informe completo, configuración y guía de uso: [`docs/INFORME.md`](docs/INFORME.md)**

```bash
npm install
npm run serve
npm test
```
